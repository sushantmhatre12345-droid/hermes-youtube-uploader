Privacy Policy

Last updated: November 3, 2026

Hermes YouTube Uploader ("the app") is a personal application owned and operated by Sushant Mhatre. It is used only by its owner to upload his own videos to his own YouTube channels (Brain Reset and Pulse Reset).

Data the app accesses

With the owner's consent via Google OAuth, the app accesses the owner's YouTube account through the YouTube Data API solely to upload videos and set their metadata (title, description, tags, privacy status, thumbnails).

How data is stored

OAuth access and refresh tokens are stored locally on the owner's personal computer only. No data is stored on any server operated by the app.

Sharing

The app does not share, sell, rent, or transfer any user data to any third party, and does not use it for advertising or any purpose other than uploading the owner's videos.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token file also removes all stored data.
